TVboxHome — лаунчер для телевизора

TVboxHome 1.2.0 — отдельное приложение для организации домашнего экрана Android TV и Google TV. Оно дополняет TVbox, но не требуется для просмотра телевидения и кино.

TVbox и TVboxHome: в чём разница

TVbox отвечает за телевидение и кинотеатр. TVboxHome — домашний экран: запуск приложений, избранные каналы и продолжение просмотра при совместном использовании с TVbox. Лаунчер бесплатен, без рекламы и может работать без TVbox.

Для чего нужен TVboxHome

Лаунчер помогает сделать домашний экран телевизора удобнее для управления пультом и быстрого перехода к приложениям.

Как установить

Скачайте APK TVboxHome 1.2.0 по прямой ссылке и установите на совместимое устройство. Возможность выбора лаунчера по умолчанию зависит от прошивки телевизора или приставки.

Как настроить домашний экран

  1. Установите APK и откройте TVboxHome из списка приложений.
  2. Выберите нужное приложение с помощью пульта и нажмите OK для запуска.
  3. Если прошивка позволяет выбирать домашнее приложение, выберите TVboxHome в системных настройках домашнего экрана либо в предложении Android при нажатии Home.
  4. Если такого выбора нет, используйте TVboxHome как обычное приложение. Заменять системные компоненты или удалять штатный лаунчер не нужно.

Названия системных пунктов зависят от производителя. Для телевидения и кино установите TVbox; общий порядок установки APK — в инструкции.

Нужен ли TVboxHome для TVbox?

Нет. TVbox и TVboxHome — самостоятельные приложения. Можно использовать только TVbox либо оба приложения вместе.
