## Данные и назначение
Для автоматического определения города и показа погоды приложение может использовать приблизительное местоположение устройства, системный сервис определения местоположения Android, данные IP-геолокации и координаты для погодного прогноза. Разрешение `ACCESS_COARSE_LOCATION` обнаружено в APK.

Статический анализ APK выявил адреса сторонних сервисов: ipapi.co, ipinfo.io, ipwho.is и api.open-meteo.com. Наличие адреса в коде **не доказывает**, что он вызывается при каждом запуске. Если запрос к внешнему сервису выполняется, соответствующий сервис может получить IP-адрес запроса; погодный API может получить координаты, используемые для прогноза.

Приложение также содержит механизм хранения данных о погоде и городе (ключи `weather_city`, `weather_updated_at`, `location_source`, `location_updated_at`). Точный срок хранения, состав данных и способы удаления пока не подтверждены.

Для запуска приложений TVboxHome использует сведения об установленных приложениях устройства. В APK обнаружено разрешение `QUERY_ALL_PACKAGES`. Необходимо подтвердить, передаётся ли список установленных приложений куда-либо за пределы устройства.
