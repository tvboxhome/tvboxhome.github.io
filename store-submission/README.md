## TVbox 2.5.6
**Название:** TVbox — телевидение и кино для Android TV

**Краткое описание:** Телеканалы, программа передач, фильмы и сериалы на Android TV и Google TV.

**Описание:** TVbox — приложение для телевизоров и приставок с Android TV и Google TV. Интерфейс рассчитан на большой экран и управление пультом. Доступны телеканалы, программа передач, избранное, поиск, фильмы и сериалы с выбором доступной озвучки, сезона и серии. Приложение не показывает собственную рекламу. Качество видео зависит от источника и устройства; для некоторых материалов доступно 4K. Минимальная версия Android — 8.0. Телефоны и планшеты не являются целевыми устройствами. Тестовый доступ заявлен до 31.12.2026.

## TVboxHome 1.2.0
**Название:** TVboxHome — лаунчер для Android TV

**Краткое описание:** Домашний экран для телевизора с быстрым запуском приложений и управлением пультом.

**Описание:** TVboxHome — бесплатный домашний экран для Android TV и Google TV без собственной рекламы. Позволяет быстро запускать приложения. При использовании с TVbox доступны избранные каналы и продолжение просмотра. TVboxHome может работать без TVbox. На устройствах, где замена системного лаунчера ограничена, приложение можно запускать как обычное.

### Проверка на Mac (ничего не меняет в APK)
```bash
SDK="$HOME/Library/Android/sdk"
APKSIGNER="$(find "$SDK/build-tools" -type f -name apksigner | sort -V | tail -1)"
test -x "$APKSIGNER" || { echo "apksigner не найден"; exit 1; }
for APK in "$HOME/Downloads/TVbox_2.5.6.apk" "$HOME/Downloads/TVboxHome_1.2.0.apk"; do
  test -f "$APK" || { echo "Файл отсутствует: $APK"; continue; }
  echo "==== $APK ===="
  shasum -a 256 "$APK"
  "$APKSIGNER" verify --verbose --print-certs "$APK"
done
```
